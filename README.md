# GAS 作業リポジトリ

Google Apps Script（GAS）のコードを Claude Code と一緒に作成・編集するためのリポジトリです。
運用は **コピペ方式**：ここで書いたコードを [GAS エディタ](https://script.google.com) に貼り付けて使います。

## フォルダ構成

```
src/
  spreadsheet.gs   スプレッドシート自動化のサンプル
  gmail.gs         Gmail 連携のサンプル
  calendar.gs      カレンダー連携のサンプル
```

`.gs` ファイルは GAS エディタのファイルにそのまま対応します。中身をコピーして貼り付けてください。

## 使い方（Claude Code との進め方）

1. やりたいことを日本語で具体的に伝える
   - 例：「A列が空欄の行に今日の日付を入れる関数を作って」
   - 例：「特定ラベルの未読メールを毎朝Slackに通知したい」
2. Claude がこのリポジトリ内にコードを書く／直す
3. できたコードを GAS エディタにコピペして実行・確認
4. 修正したい点を伝えると、Claude が更新する

## GAS エディタへの貼り付け手順（初回）

1. https://script.google.com を開く →「新しいプロジェクト」
2. 対象のスプレッドシート等から開く場合は「拡張機能 > Apps Script」
3. ファイルの中身をコピーして貼り付け → 保存（Ctrl/Cmd + S）
4. 関数を選んで「実行」。初回は権限の承認を求められます

## メモ

- 動かして出たエラーメッセージを貼ってもらえれば、原因を調べて直します。
- 既存の GAS を直したい場合は、そのコードを貼るか `src/` にファイルとして置いてください。
