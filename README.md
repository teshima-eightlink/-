# ABCカイロプラクティック整体院｜症状ページ 共通テンプレート

症状別の固定ページ（首こり・肩こり／腰痛／頭痛…）を、**同じ構成・同じ導線で量産する**ための
WordPress 固定ページテンプレート一式です。

構成は以下の7ステップで固定されています。
**①〜⑦の番号は原稿を組み立てるための目印で、ページには表示されません。**

| | セクション | 内容 |
|---|---|---|
| 冒頭 | 導入 | お悩みの声（吹き出し）＋「首や肩だけに原因があるとは限りません」 |
| ① | 共感 | 悩み（チェックリスト5つ） |
| ② | 解説 | 原因・背景（3項目・横並び） |
| ③ | 評価 | ABCでは何を確認する？（AI姿勢診断ほか6項目・タイル） |
| ④ | 方針 | どう施術する？（3ステップ） |
| ⑤ | 実例 | 症例ページへ |
| ⑥ | 専門性 | 姿勢改善ページへ |
| ⑦ | 行動 | 予約・LINE |

**デザイン・レイアウトはテンプレート側で共通化し、原稿だけを症状ごとのファイルに分ける**構造です。
2ページ目以降は、原稿ファイルを1つコピーして書き換えるだけで作れます。

---

## 既存サイトとの整合

料金ページのHTMLに合わせて、**同じ構造・同じ命名規約**で出力します。

```html
<section class="content_full">
  <div class="content_inner inner symptom__inner">
    <div class="symptom__box"> … </div>
```

クラス名は既存の `price__box` / `price__caution--inner` と同じ
「**ページ名__要素--修飾**」の形に揃えてあります（`symptom__box` / `symptom__cause--inner`）。

CSSは**症状ページにだけ出てくる部品**（チェックリスト、原因カード、確認タイル、
ステップ、予約ボックス）に限定しています。フォント・文字サイズ・行間・文字色・
見出しの装飾・本文幅は**一切指定せず、テーマ（STORY）から継承**します。

## 設置手順（初回のみ）

> **前提テーマ：TCD「STORY」（tcd041）**
> 有料テーマのため、**必ず子テーマにアップロードしてください**。親テーマに置くと、
> テーマのアップデート時にすべて消えます。

### 1. ファイルをアップロードする

`theme/` の中身を、使用中の**子テーマ**の直下にアップロードします。

```
/wp-content/themes/【子テーマ名】/page-symptom.php
/wp-content/themes/【子テーマ名】/inc/symptom-config.php
/wp-content/themes/【子テーマ名】/inc/symptom-loader.php
/wp-content/themes/【子テーマ名】/inc/symptoms/kubikori-katakori.php
/wp-content/themes/【子テーマ名】/inc/symptoms/_template.php
/wp-content/themes/【子テーマ名】/assets/css/symptom.css
```

### 2. 院の情報を設定する

`inc/symptom-config.php` を開いて設定します。

| 項目 | 状態 |
|---|---|
| `cta.line_url` | ✅ 設定済み（`https://lin.ee/VG1WL3J`） |
| `wrapper.outer` / `wrapper.inner` | ✅ 既存ページのHTMLに合わせて設定済み |
| `links.case` | ⚠️ `/case/` 暫定。症例ページの実URLに合わせてください |
| `links.posture` | ⚠️ `/posture/` 暫定。姿勢改善ページの実URLに合わせてください |
| `clinic.*` / `cta.tel` / `cta.web_url` / `cta.first_price` | ⬜ 空欄＝**非表示**（変更の可能性があるため未掲載） |

**空欄にした項目は、ページ上に自動で表示されません。**
住所や受付時間を載せたくなったら値を入れるだけで、レイアウトを崩さずに表示されます。

ここは1回設定すれば、**すべての症状ページに反映されます**。

### 3. 固定ページを作る

管理画面 →「固定ページ」→「新規追加」

| 設定 | 値 |
|---|---|
| タイトル | 首こり・肩こり |
| **スラッグ（URL）** | `kubikori-katakori` ← **原稿ファイル名と同じにする** |
| ページ属性 → テンプレート | **症状ページ（共通テンプレート）** |
| 本文 | 空のままでOK |

公開して `https://abc-chiro.net/kubikori-katakori/` を開けば完成です。

> テンプレート側で `<h1>` を出力しています。テーマのページタイトルは
> WordPress の設定で非表示にしてください。

## 2ページ目以降の作り方（横展開）

**所要5〜10分。テンプレートやCSSは一切触りません。**

1. `inc/symptoms/_template.php` をコピーし、ファイル名をスラッグにする
   例：`yotsu.php`（腰痛）、`zutsu.php`（頭痛）、`nekoze.php`（猫背）
2. ファイル内の `【 】` の部分を書き換える
3. 固定ページを新規作成し、**スラッグをファイル名と同じに**して、テンプレートを選ぶ
4. 公開

院の情報・LINE・デザインは共通設定から自動で入るため、**書くのは原稿だけ**です。

### 展開候補

| 症状 | 推奨スラッグ |
|---|---|
| 腰痛 | `yotsu` |
| 頭痛・眼精疲労 | `zutsu` |
| 猫背・巻き肩 | `nekoze` |
| 産後の骨盤の悩み | `sango-kotsuban` |
| 自律神経の乱れ・不眠 | `jiritsu-shinkei` |
| 膝の痛み | `hiza-itami` |

## 設置方法は3つ。PHPを触らない方法もあります

| | 方式A：貼り付け | 方式B：テンプレート | 方式C：ショートコード |
|---|---|---|---|
| **PHPを触る** | **不要** | 必要（ファイル設置） | 必要（functions.php に1行） |
| FTP | 不要 | 必要 | 必要 |
| 本文に置くもの | HTML全文 | 空 | `[symptom slug="…"]` |
| LINEのURL等の変更 | 全ページ個別に修正 | 設定1か所 | 設定1か所 |

**PHPを触りたくない場合は方式A**です。手順は下記のとおり。

---

## 方式A：PHPを触らない設置手順（クラシックエディタ）

### 手順1　ビジュアルエディタを切る【最初に必ず】

クラシックエディタの「ビジュアル」タブは、**切り替えた瞬間に本文のHTMLを整形し直します。**
その過程で `div` の入れ子や `class` 属性が削除され、CSSが当たらなくなります。
**1回クリックしただけで元に戻せません。**

タブ自体を消してしまうのが確実です。

> 管理画面 →「ユーザー」→「プロフィール」→
> **「ビジュアルリッチエディターを使用しない」にチェック** → 保存

これで本文欄はコード入力だけになり、誤クリックの余地がなくなります。

### 手順2　CSSを登録する【1回だけ】

> 管理画面 →「外観」→「カスタマイズ」→「**追加CSS**」

`theme/assets/css/symptom.css` の中身を**全文コピーして貼り付け**、公開します。
すべての症状ページで共通なので、**この作業は最初の1回だけ**です。

### 手順3　固定ページを作る

1. 「固定ページ」→「新規追加」
2. タイトル：`首こり・肩こり`、スラッグ：`kubikori-katakori`
3. 本文欄に `paste/kubikori-katakori.html` の中身を**全文コピーして貼り付け**
4. 公開

### 注意点

- **管理者権限で作業してください。** 編集者以下の権限では、WordPressが
  `section` タグや `class` 属性を自動的に削除します（`unfiltered_html` 権限が必要）。
- 貼り付け用HTMLは、クラシックエディタの自動整形（`wpautop`）で崩れないよう、
  **空行をなくし、改行をタグの境目だけに置いた形**で生成しています。
  手で編集して空行を入れると、余計な段落が入ることがあります。
- 原稿を直して `paste/` を作り直したら、次のコマンドで検証してください。

```bash
php tools/build-preview.php     # HTMLを作り直す
php tools/test-autop.php        # 自動整形で崩れないか検証する
```

## 方式B・C（PHPを触ってよい場合）

原稿をテーマ内のファイルで一元管理できるため、**ページ数が増えるほど有利**です。
LINEのURLや院名を変えるとき、方式Aは全ページを個別に直しますが、
方式B・Cは設定ファイル1か所で済みます。

### 方式B：固定ページテンプレート

`theme/` の中身を子テーマにアップロードし、固定ページの
「ページ属性 → テンプレート」で「症状ページ（共通テンプレート）」を選ぶだけです。
**本文は空**なので、エディタで何をしても壊れません。

### 方式C：ショートコード

子テーマの `functions.php` に次の1行を追加すると使えます。

```php
require_once get_theme_file_path( 'inc/symptom-shortcode.php' );
```

固定ページの本文に置くのは、この1行だけです。

```
[symptom slug="kubikori-katakori"]
```

エディタから見ればただの文字列なので、タブを切り替えても壊れません。
テーマ指定のページテンプレートを使いたい場合や、他のコンテンツと
並べたい場合は、方式Bよりこちらが向いています。

`preview/kubikori-katakori.html` をブラウザで開けば、レイアウトを確認できます。


ヘッダー・フッターと、フォント・見出しの書式は「仮テーマ」のものです。
実サイトでは STORY のスタイルに置き換わります。

## アクセントカラー（テーマカラー cyan への対応）

テーマカラー **#00ffff** に合わせていますが、**そのままでは文字や線に使えません**。
白背景に対するコントラスト比が **1.25:1** しかなく、WCAG AA の本文基準（4.5:1）を大きく下回ります。

そこで、色相180°（純粋なシアン）を保ったまま、**用途で2つに分けています**。

| 変数 | 値 | 用途 | 白地でのコントラスト |
|---|---|---|---|
| `--symptom-accent` | `#008080` | 文字・番号・チェックマークなど**意味を持つ要素** | **4.77:1**（AA適合） |
| `--symptom-accent-bright` | `#00ffff` | 確認タイルの下線・予約ボックス上辺・マーカー | 装飾のみ |

`symptom.css` 冒頭の2行を書き換えれば、全ページに反映されます。
`--symptom-accent` は `#0a8a8a`（4.19:1）程度までなら明るくできますが、
それ以上は細い線や小さな文字が読みにくくなります。

## 原稿を書くときのルール

### 分量（読み疲れさせないため）

- 1つの説明は **1〜2文まで**。3文以上になったら削る
- 箇条書きは **1行におさめる**
- ②の原因は **3つ**、①のチェックリストは **5つ**、③の確認項目は **6つ固定**

### 全症状で共通にする部分

- **③ ABCでは何を確認する？** … AI姿勢診断／頭・肩の位置／背骨のバランス／骨盤の傾き／
  肩甲骨周囲の動き／日常生活や身体の使い方 の6項目。見出しは固定し、説明文だけを症状に寄せる
- **④の注意書き／末尾の免責文** … 表現リスク対策のため、削らずに残す

### 薬機法・景表法

整体院は医療機関ではないため、表現に制限があります。

**使わない表現**

- 「治る」「治ります」「改善します」「効果があります」などの断定・効果保証
- 「治療」「患者様」「診断」（→「施術」「お客様」「確認」）
  ※「AI姿勢診断」はサービス名として既存サイトで使われているため、そのまま使用

**使ってよい表現**

- 「〜を目指します」「〜な方が多くいらっしゃいます」「〜を確認します」

### ⑤実例（症例）セクション

`cases.items` は**空の状態で納品しています**。
架空の体験談は景品表示法（ステマ規制）に抵触するおそれがあるため、
**実際の症例のみ**を入れてください。書き方の例は原稿ファイル内のコメントにあります。
空のままなら、リード文と症例ページへのリンクだけが表示されます。

## よくあるトラブル

| 症状 | 原因と対処 |
|---|---|
| 固定ページの本文しか出ない | スラッグと原稿ファイル名が一致していません。管理者でログインした状態で表示すると、探したファイル名が画面に出ます |
| テンプレートが選択肢に出てこない | `page-symptom.php` が**テーマ直下**にあるか確認してください |
| ボタンが表示されない | `symptom-config.php` の該当URLが空です。空欄の項目は意図的に非表示になります |
| 左右の余白が他ページと違う | `wrapper.inner` のクラス名が実際のテーマと合っているか確認してください |
| デザインが崩れる | テーマ側のCSSが強く効いている可能性があります。`.symptom__inner` を含むセレクタで上書きしてください |
