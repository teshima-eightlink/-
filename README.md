# GAS プロジェクト集

運用は **コピペ方式**：各 `.gs` の中身を [GAS エディタ](https://script.google.com) に貼り付けて使います。

## ファイル

```
src/camera_management.gs   撮影管理シート × Googleカレンダー連携
src/line_hub.gs            LINE貼付ハブ（修正管理・修正完了ログ・納品完了ログ）
```

# 撮影管理 GAS

Google スプレッドシート「撮影管理」シートと Google カレンダーを連携する Apps Script です（`src/camera_management.gs`）。

## 列レイアウト

| 列 | 内容 | 列 | 内容 |
|---|---|---|---|
| A | カメラマンマスタ | K | 撮影終了 ☑ |
| B | 案件名 | L | 納品 ☑ |
| C | 候補日メモ | M | UP ☑ |
| D | 撮影日 | N | データ譲渡 ☑ |
| E | 時間 | O | 詳細送付ID |
| F | 撮影場所 | P | 前日確認ID |
| G | カメラマン | Q | 撮影ID |
| H | カメラマン住所 | R | 納品ID |
| I | カレンダー（同期） | S | メモ |
| J | 状態 | | |

## メニュー（シートを開くと「撮影管理」メニューが出ます）

- **カレンダー同期** … I列が「登録・更新する」の行をカレンダーに登録／更新（`syncCameraTasks`）
- **撮影終了を下に移動** … 状態を反映してから、状態が「撮影終了」の行を下へ並べ替え（`moveFinishedDown`）
- **【初期設定】シートの環境を整える** … 見出し・プルダウン・チェックボックス等を設定（`setSheetCameraTasks`）

## J列（状態）の仕様

| 状態 | 意味 | 決まり方 |
|---|---|---|
| （空白） | 進行中 | 初期状態 |
| 撮影終了 | 撮影完了 | 撮影終了・納品・UP のいずれかにチェック → 「撮影終了を下に移動」実行時に自動設定 |
| 中止 | 中止・削除済 | 手動で選ぶ、または I列が「削除済」になったとき自動設定 |

- **編集時に自動反映**：K〜M（撮影終了・納品・UP）のいずれかにチェックを入れると、その行の J列が自動で「撮影終了」になります（`handleCheckboxEdit`）。
  - `onEdit` という名前は使わず、**インストール型トリガー**で実行するため他のGASと衝突しません。
  - 初回のみメニュー「**【初回のみ】編集時の自動反映を設定**」を実行してトリガーを登録してください（`installEditTrigger`）。
- 「**撮影終了を下に移動**」でも、実行時に同じ判定で J列を「撮影終了」に更新してから並べ替えます（`applyFinishedStatus` → 並べ替え）。
  - 並べ替えは「未終了の案件」→「空行を1行」→「撮影終了の案件」の順に**上へ詰めて**配置します（空行を無視するので、大量の空行の下まで飛ぶことはありません）。
- カレンダー同期で「削除する」または「中止」の行を処理すると、I列を「削除済」・J列を「中止」に更新し、カレンダーの予定を削除します。

## 使い方（初回）

1. 「拡張機能 > Apps Script」を開き、`src/camera_management.gs` の中身を貼り付けて保存
2. シートを開き直して「撮影管理」メニュー →「【初期設定】シートの環境を整える」を実行
3. 案件を入力し、I列で「登録・更新する」を選んで「カレンダー同期」を実行

> 注意：`syncCameraTasks` 内の `CALENDAR_ID` は連携先カレンダーのIDです。変更する場合はここを編集してください。

# LINE貼付ハブ GAS

「LINE貼付」シートに種別を選んでLINE本文を貼ると、種別ごとに解析して各シートへ振り分ける仕組みです（`src/line_hub.gs`）。

## 種別と転記先

| 種別 | 転記先シート |
|---|---|
| 修正依頼 | 修正管理 |
| 修正完了 | 修正完了ログ |
| 納品完了 | 納品完了ログ |
| その他 | （転記なし） |

## 納品完了ログ の列

| 列 | 項目 | 取得元 |
|---|---|---|
| A | 貼り付け日 | 解析日 |
| B | 区分（TOP / 全ページ） | 本文判定 |
| C | 状態（未対応 / 対応中 / 対応完了） | プルダウン（手入力） |
| D | 案件名 ★ | 軽量版案件一覧（URL照合） |
| E | URL | 本文 |
| F | 制作担当 ★ | 軽量版案件一覧（URL照合） |
| G | CMSログイン先 ★ | 軽量版案件一覧（URL照合） |
| H | ドキュメント | 手入力 |
| I | 備考 | 手入力 |
| J/K | 納品ID・元LINE行 | 管理用（非表示） |

- **★** の項目は「軽量版案件一覧」シートを URL で照合して取得します（軽量版に無い場合、案件名のみ本文抽出をフォールバック）。
- **案件名の抽出**：本文中の「URLの直前の行」を案件名とみなし、敬称（様/さん）・完了文言・記号を除去します。
- **区分の判定**：本文に「全ページ」記載→全ページ、「TOP」記載→TOP、どちらも無し→全ページ。
- 状態・ドキュメント・備考の手入力は、再解析（`runLineHub`）しても納品IDで保持されます。

## 使い方

1. `src/line_hub.gs` を貼り付けて保存
2. `setupLineHubSheets` を実行（各シートとプルダウンを作成）
3. 「LINE貼付」シートの A列で種別を選び、B列にLINE本文を貼る
4. `runLineHub` を実行 → 解析して各シートへ転記

> 注意：`LINE_HUB_CONFIG` の `SPREADSHEET_ID` / `LIGHTWEIGHT_SPREADSHEET_ID` は対象スプレッドシートのIDです。軽量版案件一覧の見出し（制作担当・CMSログイン先など）は `getLightweightMap_` の候補名で照合します。実際の列名が異なる場合はここに追加してください。
