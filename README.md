# 撮影管理 GAS

Google スプレッドシート「撮影管理」シートと Google カレンダーを連携する Apps Script です。
運用は **コピペ方式**：`src/camera_management.gs` の中身を [GAS エディタ](https://script.google.com) に貼り付けて使います。

## ファイル

```
src/camera_management.gs   撮影管理シートのメインスクリプト
```

## 列レイアウト

| 列 | 内容 | 列 | 内容 |
|---|---|---|---|
| A | カメラマンマスタ | K | 撮影終了 ☑ |
| B | 案件名 | L | 納品 ☑ |
| C | 候補日メモ | M | UP ☑ |
| D | 撮影日 | N | データ譲渡 ☑ |
| E | 時間 | O | 詳細送付ID |
| F | 撮影場所 | P | 前日確認ID |
| G | カメラマン | Q | 撮影ID |
| H | カメラマン住所 | R | 納品ID |
| I | カレンダー（同期） | S | メモ |
| J | 状態 | | |

## メニュー（シートを開くと「撮影管理」メニューが出ます）

- **カレンダー同期** … I列が「登録・更新する」の行をカレンダーに登録／更新（`syncCameraTasks`）
- **撮影終了を下に移動** … 状態を反映してから、状態が「撮影終了」の行を下へ並べ替え（`moveFinishedDown`）
- **【初期設定】シートの環境を整える** … 見出し・プルダウン・チェックボックス等を設定（`setSheetCameraTasks`）

## J列（状態）の仕様

| 状態 | 意味 | 決まり方 |
|---|---|---|
| （空白） | 進行中 | 初期状態 |
| 撮影終了 | 撮影完了 | 撮影終了・納品・UP のいずれかにチェック → 「撮影終了を下に移動」実行時に自動設定 |
| 中止 | 中止・削除済 | 手動で選ぶ、または I列が「削除済」になったとき自動設定 |

- **編集時に自動反映**：K〜M（撮影終了・納品・UP）のいずれかにチェックを入れると、その行の J列が自動で「撮影終了」になります（`handleCheckboxEdit`）。
  - `onEdit` という名前は使わず、**インストール型トリガー**で実行するため他のGASと衝突しません。
  - 初回のみメニュー「**【初回のみ】編集時の自動反映を設定**」を実行してトリガーを登録してください（`installEditTrigger`）。
- 「**撮影終了を下に移動**」でも、実行時に同じ判定で J列を「撮影終了」に更新してから並べ替えます（`applyFinishedStatus` → 並べ替え）。
  - 並べ替えは「未終了の案件」→「空行を1行」→「撮影終了の案件」の順に**上へ詰めて**配置します（空行を無視するので、大量の空行の下まで飛ぶことはありません）。
- カレンダー同期で「削除する」または「中止」の行を処理すると、I列を「削除済」・J列を「中止」に更新し、カレンダーの予定を削除します。

## 使い方（初回）

1. 「拡張機能 > Apps Script」を開き、`src/camera_management.gs` の中身を貼り付けて保存
2. シートを開き直して「撮影管理」メニュー →「【初期設定】シートの環境を整える」を実行
3. 案件を入力し、I列で「登録・更新する」を選んで「カレンダー同期」を実行

> 注意：`syncCameraTasks` 内の `CALENDAR_ID` は連携先カレンダーのIDです。変更する場合はここを編集してください。
