# ABCカイロプラクティック整体院｜症状ページ 共通テンプレート

症状別の固定ページ（首こり・肩こり／腰痛／頭痛…）を、**同じ構成・同じ導線で量産する**ための
WordPress 固定ページテンプレート一式です。

構成は以下の7ステップで固定されています。

| | セクション | 内容 |
|---|---|---|
| 冒頭 | 導入 | お悩みの声（吹き出し）＋「首や肩だけに原因があるとは限りません」 |
| ① | 共感 | 悩み（チェックリスト） |
| ② | 解説 | 原因・背景 |
| ③ | 評価 | ABCでは何を確認する？（AI姿勢分析ほか6項目） |
| ④ | 方針 | どう施術する？ |
| ⑤ | 実例 | 症例ページへ |
| ⑥ | 専門性 | 姿勢改善ページへ |
| ⑦ | 行動 | 予約・LINE |

**デザイン・レイアウトはテンプレート側で共通化し、原稿だけを症状ごとのファイルに分ける**構造です。
2ページ目以降は、原稿ファイルを1つコピーして書き換えるだけで作れます。

---

## ファイル構成

```
theme/                              ← この中身を（子）テーマにアップロードします
├── page-symptom.php                固定ページテンプレート本体（触る必要なし）
├── inc/
│   ├── symptom-config.php          ★院の情報・電話・LINE・リンク先（最初に設定）
│   ├── symptom-loader.php          共通処理（触る必要なし）
│   └── symptoms/
│       ├── kubikori-katakori.php   ★首こり・肩こりの原稿
│       └── _template.php           新しい症状を追加するときのコピー元
└── assets/css/symptom.css          デザイン（配色はファイル冒頭の変数で変更可）

preview/kubikori-katakori.html      ブラウザで表示確認できる静的プレビュー
tools/build-preview.php             プレビューを再生成するスクリプト（開発用）
```

## 設置手順（初回のみ）

### 1. ファイルをアップロードする

`theme/` の中身を、**使用中の子テーマ**（なければ親テーマ）の直下にアップロードします。
FTP でも、WordPress 管理画面の「テーマファイルエディター」でも構いません。

```
/wp-content/themes/【テーマ名】/page-symptom.php
/wp-content/themes/【テーマ名】/inc/symptom-config.php
/wp-content/themes/【テーマ名】/inc/symptom-loader.php
/wp-content/themes/【テーマ名】/inc/symptoms/kubikori-katakori.php
/wp-content/themes/【テーマ名】/inc/symptoms/_template.php
/wp-content/themes/【テーマ名】/assets/css/symptom.css
```

> 親テーマに直接置くと、テーマ更新時に消えます。子テーマを推奨します。

### 2. 院の情報を設定する

`inc/symptom-config.php` を開き、`★要設定` のコメントが付いた項目を埋めます。

**現在の設定状況**

| 項目 | 状態 |
|---|---|
| `cta.line_url` | ✅ 設定済み（`https://lin.ee/VG1WL3J`） |
| `clinic.address` / `access` / `hours` / `holiday` | ⬜ 空欄＝**非表示**（変更の可能性があるため未掲載） |
| `cta.tel` / `web_url` / `first_price` | ⬜ 空欄＝**非表示**（LINEのみの導線） |
| `links.case` | ⚠️ `/case/` 暫定。症例ページの実URLに合わせてください |
| `links.posture` | ⚠️ `/posture/` 暫定。姿勢改善ページの実URLに合わせてください |

**空欄にした項目は、ページ上に自動で表示されません。**
住所や受付時間を載せたくなったら値を入れるだけで、レイアウトを崩さずに表示されます。

ここは1回設定すれば、**すべての症状ページに反映されます**。

### 3. 固定ページを作る

管理画面 →「固定ページ」→「新規追加」

| 設定 | 値 |
|---|---|
| タイトル | 首こり・肩こり |
| **スラッグ（URL）** | `kubikori-katakori` ← **原稿ファイル名と同じにする** |
| ページ属性 → テンプレート | **症状ページ（共通テンプレート）** |
| 本文 | 空のままでOK |

公開して `https://abc-chiro.net/kubikori-katakori/` を開けば完成です。

> **本文は空で構いません。** 表示される内容は `inc/symptoms/kubikori-katakori.php` に書かれています。
> スラッグとファイル名が一致しない場合は、固定ページのカスタムフィールドに
> `symptom_slug` = ファイル名 を設定しても紐づけられます。

## 2ページ目以降の作り方（横展開）

**所要5〜10分。テンプレートやCSSは一切触りません。**

1. `inc/symptoms/_template.php` をコピーし、ファイル名をスラッグにする
   例：`yotsu.php`（腰痛）、`zutsu.php`（頭痛）、`jiritsu-shinkei.php`（自律神経の乱れ）
2. ファイル内の `【 】` の部分を、その症状の内容に書き換える
3. 固定ページを新規作成し、**スラッグをファイル名と同じに**して、テンプレートに「症状ページ（共通テンプレート）」を選ぶ
4. 公開

院の情報・電話番号・LINE・デザインは共通設定から自動で入るため、**書くのは原稿だけ**です。

## 表示を確認する（アップロード前）

`preview/kubikori-katakori.html` をブラウザで開けば、レイアウトを確認できます。
原稿を書き換えたあとに作り直すには、PHP が入った環境で次を実行します。

```bash
php tools/build-preview.php                     # 全症状ぶんを再生成
php tools/build-preview.php kubikori-katakori   # 1つだけ再生成
```

ヘッダー・フッターは実サイトのテーマのものに置き換わります。
プレビュー内の「【プレビュー用】」表記は、`inc/symptom-config.php` を設定すれば実際の値になります。

## デザインの考え方（他ページとの統一感）

**このページ用のCSSは、テーマのデザインを上書きしません。**
症状ページだけ浮いてしまわないよう、役割をはっきり分けています。

| | 担当 |
|---|---|
| フォント・文字サイズ・行間・文字色・背景色 | **テーマ**（symptom.css は一切指定しません） |
| 見出し（h1/h2/h3）の見た目・リンク色・本文幅 | **テーマ**（そのまま継承します） |
| セクションの並び・余白・箱組み（カード／リスト／ステップ） | symptom.css |

アクセントカラーの初期値は `currentColor`（＝テーマの文字色）です。
**何も設定しなければ、配色はテーマのまま**になり、色味の面では他ページと差が出ません。

### ブランドカラーに合わせる

サイトで使われている色に寄せたい場合は、`assets/css/symptom.css` 冒頭の1行だけ変更します。

```css
--abc-accent: #1f6f8b;   /* サイトのメインカラーに置き換えてください */
```

チェックマーク、番号、ステップの点、強調の縦線がこの色になります。

### そのほか調整できる変数

```css
--abc-tint: rgba(0, 0, 0, .035);   /* カードなどの面の色（薄く沈める指定） */
--abc-border: rgba(0, 0, 0, .14);  /* 罫線 */
--abc-width: 100%;                 /* 本文幅。テーマの幅をそのまま使います */
--abc-gap: 3.4em;                  /* セクション間の余白 */
```

### もっとメリハリを付けたい場合

`symptom.css` の末尾に、セクションへ背景色を付けるプリセットをコメントアウトで用意しています。
コメントを外すとランディングページ寄りの印象になります。
**他ページとの統一感より訴求力を優先したいときだけ**有効にしてください。

### ページタイトルが二重に出る場合

テーマによっては、固定ページのタイトルを自動でヘッダー部分に表示します。
その場合、原稿ファイルの `hero` に次の1行を足すと、テンプレート側のタイトルが消えます。

```php
'hero' => array(
    'show_title' => false,
    ...
```

CSS はテンプレートが `<style>` として自動で読み込みます。**functions.php の編集は不要**です。
もし正式に enqueue したい場合は、子テーマの `functions.php` に以下を追加してください
（テンプレート側が二重読み込みを自動で回避します）。

```php
add_action( 'wp_enqueue_scripts', function () {
	if ( is_page_template( 'page-symptom.php' ) ) {
		wp_enqueue_style(
			'abc-symptom',
			get_theme_file_uri( 'assets/css/symptom.css' ),
			array(),
			filemtime( get_theme_file_path( 'assets/css/symptom.css' ) )
		);
	}
} );
```

## 原稿を書くときの注意（薬機法・景表法）

整体院・カイロプラクティックは医療機関ではないため、表現に制限があります。
原稿ファイル内はこのルールに沿って書いてあります。**書き換える際も維持してください。**

**使わない表現**

- 「治る」「治ります」「改善します」「効果があります」などの断定・効果保証
- 「治療」「患者様」「診断」（→「施術」「お客様」「確認」）
- 「肩こりが治る整体」「〇〇に効く」といった見出し

**使ってよい表現**

- 「〜を目指します」「〜な方が多くいらっしゃいます」「〜を確認します」

**全症状で共通にしている部分**

次の2つは、症状が変わっても内容を揃えることでサイト全体の一貫性が出ます。ひな形にも同じ文言を入れてあります。

- **③ ABCでは何を確認する？** … AI姿勢分析／頭・肩の位置／背骨のバランス／骨盤の傾き／肩甲骨周囲の動き／日常生活や身体の使い方 の6項目。見出しは固定し、各項目の説明文だけをその症状に寄せてください。
- **④ 方針の注意書き／末尾の免責文** … 表現リスク対策のため、削らずに残してください。

**⑤実例（症例）セクションについて**

`cases.items` は**空の状態で納品しています**。
架空の体験談を掲載すると景品表示法（ステマ規制）に抵触するおそれがあるため、
**実際の症例のみ**を入れてください。書き方の例は原稿ファイル内のコメントに記載しています。
実例が用意できるまでは空のままで、リード文と症例ページへのリンクだけが表示されます。

ページ末尾には、`inc/symptom-config.php` の `disclaimer` に設定した免責文が全ページ共通で表示されます。

## よくあるトラブル

| 症状 | 原因と対処 |
|---|---|
| ページが真っ白／固定ページの本文しか出ない | 固定ページのスラッグと原稿ファイル名が一致していません。管理者でログインした状態で表示すると、画面下にどのファイルを探したかが表示されます |
| テンプレートが選択肢に出てこない | `page-symptom.php` が**テーマ直下**（サブフォルダでない場所）にあるか確認してください |
| ボタンが表示されない | `inc/symptom-config.php` の該当URLが空です。空欄の項目は意図的に非表示になります |
| デザインが崩れる | テーマ側のCSSが強く効いている可能性があります。`.abc-symptom` を含むセレクタで上書きしてください |
